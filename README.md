# OFFSHOREATSEA_JOB — бот автопостинга вакансий

Готовый бот: принимает вакансии текстом в личке, приводит к единому шаблону
(судно/регион/дата/ротация/требования/контакт + автохэштеги), проверяет
дубликаты, публикует сразу или ставит в очередь дайджеста, считает клики
по кнопке «Откликнуться».

## Быстрый старт

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумайте имя и username (заканчивается на `bot`)
3. Скопируйте токен, который пришлёт BotFather

### 2. Узнайте свой Telegram ID

Напишите [@userinfobot](https://t.me/userinfobot) — пришлёт ваш числовой ID.

### 3. Добавьте бота в канал администратором

Настройки канала → Администраторы → Добавить → найдите бота по username →
дайте право «Публикация сообщений».

### 4. Заполните конфиг

Скопируйте `.env.example` в `.env` и впишите:
- `BOT_TOKEN` — из шага 1
- `BOT_USERNAME` — username бота без `@`
- `ADMIN_IDS` — ваш ID из шага 2
- `CHANNEL_USERNAME` — username канала без `@` (сейчас `offshoreatsea`)
- `APPLY_BOT_LINK` — куда вести кнопку «Откликнуться» (пока можно оставить
  ссылку на сам канал, поменять — дело одной строчки в `.env`, перезапуск
  не потребует правки кода)

### 5. Деплой на Railway (бесплатно, без сервера)

1. Зарегистрируйтесь на [railway.app](https://railway.app) через GitHub
2. Залейте эту папку целиком в новый репозиторий на GitHub
   (через веб-интерфейс GitHub — кнопка "Add file" → "Upload files",
   консоль не обязательна)
3. В Railway: **New Project → Deploy from GitHub repo** → выберите репозиторий
4. Во вкладке **Variables** добавьте все переменные из вашего `.env`
   (`BOT_TOKEN`, `BOT_USERNAME`, `ADMIN_IDS`, `CHANNEL_USERNAME`, `APPLY_BOT_LINK`)
5. Railway сам поставит зависимости и запустит бота (используется `Procfile`)
6. Проверьте вкладку **Deployments → Logs** — ошибок быть не должно
7. Откройте бота в Telegram, отправьте `/start` — должен ответить

Если хотите добавить свой часовой пояс для дайджест-расписания (по умолчанию
Railway использует UTC) — добавьте переменную `TZ` со значением вашего пояса,
например `TZ=Europe/Moscow`.

## Как пользоваться

- Пришлите боту текст вакансии в личку — бот разберёт поля и покажет превью
  с тремя кнопками: **Опубликовать сейчас** / **В очередь (дайджест)** / **Отмена**
- Несколько вакансий сразу — разделяйте строкой из трёх дефисов: `---`
- Дайджест выходит по расписанию 09:00 / 14:00 / 19:00 — время задаётся в
  начале `main.py`, константа `DIGEST_TIMES`
- `/stats` — сводка за 7 дней: сколько опубликовано, топ-5 по кликам

## Формат, в который приводится любая вакансия

```
⚓ Должность

🚢 Судно: ...
🌍 Регион: ...
📅 Дата: ...
🔄 Ротация: ...

✅ Требования:
• ...

📩 Контакт: ...
#хэштеги
```

Поля определяются по ключевым словам и шаблонам в тексте (не ИИ) — если
что-то не нашлось, на его месте будет «—». Донастроить списки ключевых слов
можно в начале `main.py` (`REGIONS`, `VESSEL_TYPES`).
